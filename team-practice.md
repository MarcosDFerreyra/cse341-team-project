# Team Practice Notes
Hi everyone! this is the workflow for the pull requests that we all must practice
## Pull Request Workflow
- Pull the latest `main` branch before starting a new branch.
- Include testing notes in every pull request.
- Ask for review in the team Microsoft Teams channel when a PR is ready.
- Use a short branch name that describes the change (for example `eduar-practice-notes`).
- Get at least one teammate's approval before merging into `main`.

## Pull Request Workflow

- Always pull the latest changes from the `main` branch before starting new work.
- Use descriptive branch names for every task.
- Include testing notes in every pull request.
- Review another team member's code before approving a pull request.
- Keep commits small and use clear commit messages.
- Ask for review in the team Microsoft Teams channel when a PR is ready.
